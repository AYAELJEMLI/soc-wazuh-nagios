Push mobile — Ntfy (gratuit)
Ntfy envoie des notifications push instantanées sur Android/iOS sans compte. Installez l'app et abonnez-vous au topic.
# Test depuis VM Nagios curl -d "HOST DOWN: wazuh-manager" \ -H "Title: SOC Alert" \ -H "Priority: urgent" \ ntfy.sh/soc-emsi-2026
Commandes Nagios — commands.cfg
# Notification HOST via Ntfy define command { command_name notify-host-ntfy command_line curl -d \ "[$HOSTSTATE$] $HOSTALIAS$" \ ntfy.sh/soc-emsi-2026 } # Notification SERVICE via Ntfy define command { command_name notify-service-ntfy command_line curl -d \ "[$SERVICESTATE$] $SERVICEDESC$" \ ntfy.sh/soc-emsi-2026 }
Telegram Bot
# Envoyer une alerte Telegram curl -s -X POST \ https://api.telegram.org/bot{TOKEN}/sendMessage \ -d chat_id={CHAT_ID} \ -d text="CRITICAL: HOST DOWN"
Accès mobile — Déploiement
Ce dashboard est mobile-first — fonctionne sur tout navigateur téléphone via Tailscale
Déployer sur la VM Nagios
# Copier le dashboard sur Nagios sudo cp soc_dashboard.html \ /usr/local/nagios/share/soc.html # URL d'accès mobile http://10.0.0.20/nagios/soc.html
Ajouter à l'écran d'accueil (PWA)
iPhone / Safari :
Partager → "Sur l'écran d'accueil"

Android / Chrome :
Menu (⋮) → "Ajouter à l'écran d'accueil"

Résultat :
Icône SOC Platform sur votre bureau, plein écran, navigation bottom-bar, accès Wazuh et Nagios en un tap.
